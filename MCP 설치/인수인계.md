# 인스타툰 이미지 MCP 설치 프로그램 인수인계

작성일: 2026-10-30. 이 문서는 키를 포함하지 않습니다.

## 1. 목표
- Claude Code에서 인스타툰을 기획·제작할 때 OpenAI GPT Image로 이미지를 만들게 한다.
- 다른 사람의 Windows 노트북에서 ZIP을 풀고 `install.bat`만 실행하면 연결되게 한다. 그 노트북에서 문제가 나면 사용자가 직접 고칠 수 없으므로 안내 문구까지 중요하다.
- 전제: 받는 사람은 Claude를 구독 중이고 Claude 앱과 Claude Code가 정상 동작한다. 앱 개발 경험은 없다.
- 전달 방법: 폴더를 ZIP으로 압축해 슬랙으로 보낸다.

## 2. 사용자 응대 원칙
- 한국어로, 묻는 것만, 짧고 정확하게 답한다. 중학생도 알아들을 수 있게 설명한다.
- 사실과 추측을 구분하고, 직접 확인한 것만 "문제없음"이라고 한다.
- 빈말과 불필요한 제안을 하지 않는다.
- 작업 중 실수와 부작용은 숨기지 않고 알린다.

## 3. 현재 상태 요약
- 설치 파일 수정과 임시 폴더 시험은 끝났다.
- **남은 핵심: 이 노트북에서 `install.bat`을 다시 실행해 진짜 그림 생성을 확인하는 것.**
- 사용자가 수정 전 버전으로 한 번 실행했고, 시험 그림만 `400 The model 'gpt-image-1' does not exist.`로 실패했다. 이후 `gpt-image-2`로 고쳤지만 진짜 키로 재시험은 하지 않았다.

## 5. 설치 프로그램 동작 순서
1. 입력 불가 환경이면 "더블클릭하세요" 안내 후 종료
2. 이전 실행의 임시 파일과 시험 프로세스 정리 (기록된 PID 중 이 설치의 것만)
3. ARM 윈도우면 중단
4. Node 확인. 없으면 winget 설치 시도. 22, 24, 26만 허용
5. Claude 실행 중이면 종료 요청 (`s`로 건너뛰기 가능)
6. registry.npmjs.org, github.com, api.openai.com 접속 확인. 막히면 이름을 알리고 중단
7. `%LOCALAPPDATA%\openai-gpt-image-mcp`에 `npm ci --ignore-scripts` + `prebuild-install`로 설치
8. 설치 사본의 기본 모델을 `gpt-image-2`로 변경
9. API 키 입력과 확인
10. `.claude.json` 백업 후 등록 (키가 든 백업은 최근 3개만 보관)
11. 권한 허용 (선택, `settings.json` 백업 후 수정)
12. 서버 연결, tools/list 확인, 시험 이미지 1장 생성 (`gpt-image-2`, low, 1024x1024)

등록 형식: 명령은 node.exe 절대 경로, 인자는 서버 `index.js` 경로, 환경변수는 `OPENAI_API_KEY`와 `OPENAI_IMAGE_OUTPUT_DIR`(셸 폴더 기준 실제 다운로드 폴더 + `openai-images`).

## 6. 주요 결정과 이유
| 결정 | 이유 |
|---|---|
| npx 대신 고정 폴더 + 잠금 파일 | 하위 부품 버전 고정, npm 차단 시 시작이 72초에서 0.6초로 단축 |
| Node 22, 24, 26만 허용 | 18, 20은 실제 실패. 23은 미리 빌드된 파일 없음. 25는 미검증이라 제외 |
| ARM 차단 | `sharp` 0.33.5에 ARM용 파일 없음 (실행해 보지는 못함) |
| 컴파일 시도 금지 (`--ignore-scripts`) | 다운로드 실패 시 node-gyp가 Python 설치 관리자를 실행하는 것을 확인 |
| 오류를 HTTP 상태·오류 코드로 분류 | 문장 속 단어로 판단하면 요청 과다를 크레딧 부족으로 오인 |
| 시험 때만 API 응답 기록 | 도구의 오류 문장에는 오류 코드가 없음 |
| 설치 사본의 기본 모델 변경 | 패키지 기본값 `gpt-image-1`이 코드에 고정, 변경 설정 없음 |

OpenAI 공지: `gpt-image-1`은 2026-10-23 종료, `gpt-image-1.5`는 2026-12-01 종료 예정, 대체는 `gpt-image-2`. 실패 원인이 이 종료라는 것은 공지와 오류 문구를 맞춘 추측이다. 모델 목록에는 `gpt-image-1`이 아직 보인다.

## 11. 작업 규칙
- 사용자의 실제 `.claude.json`, `settings.json`은 시험 때 건드리지 않는다. `USERPROFILE`, `LOCALAPPDATA`, `TEMP`, `CLAUDE_CONFIG_DIR`, `OPENAI_IMAGE_OUTPUT_DIR`을 임시 폴더로 지정한다.
- 키 값을 출력하지 않는다. 사용자에게 키를 채팅에 붙여넣게 하지 않는다.
- 실행 중인 Claude와 MCP 서버를 종료하지 않는다. 시험에서 띄운 프로세스만 PID로 정리한다. 이전에 이름으로 찾아 종료했다가 실행 중인 MCP 서버까지 끈 적이 있다.
- 진짜 이미지 생성은 비용이 드니 사용자 승인 후에만 한다.
- 코드를 바꾸면 `CHANGELOG.md`에 이유를 한 줄 기록한다.

## 12. 시험 코드 작성 시 주의 (실제로 겪은 실수)
- PowerShell 변수는 대소문자를 구분하지 않는다: `$T`와 `$t`는 같다.
- `H`는 `Get-History` 별칭이다. 이 이름의 함수를 쓰면 경로가 비어 `C:\` 아래에 파일이 생긴다.
- `New-Item`에는 `-LiteralPath`가 없다. `[IO.Directory]::CreateDirectory()`를 쓴다.
- `Invoke-ScriptAnalyzer`에도 `-LiteralPath`가 없다. `-Path`를 쓴다.
- PowerShell 5.1의 `ConvertFrom-Json`은 `package-lock.json`을 읽지 못한다. node로 읽는다.
- 스크립트 안 JS는 ASCII로 저장되므로 한글을 넣으면 깨진다. 도구 입력의 `\uXXXX`는 실제 문자로 바뀌어 저장되니 이스케이프로도 피할 수 없다.
- 시험 뒤 작업 폴더에 `Microsoft\Windows\PowerShell\ModuleAnalysisCache`가 생길 수 있다. 내용을 확인하고 지운다.
- `Read-Host -AsSecureString`은 표준입력을 넘겨도 받지 못한다. 시험에서는 `Read-Host` 함수를 대체하고, 입력 가능 검사를 뺀 사본으로 돌린다. 진짜 입력 불가 검사는 원본으로 시험한다.
- 시험 스크립트 일부는 지난 세션 임시 폴더에 있어 없어질 수 있다: `C:\Users\김우진\AppData\Local\Temp\claude\C--Users-----Desktop-----MCP---\833288b6-c560-4c32-95c0-abf9fc652095\scratchpad`
