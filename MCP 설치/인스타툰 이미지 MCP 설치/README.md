# 인스타툰 이미지 생성용 MCP 설치 (Windows)

**실행 전 체크리스트**
- [ ] 이미지 도구는 Claude 앱의 **Code 탭**에서만 쓸 수 있고, 일반 채팅에서는 안 보인다는 점을 확인했다
- [ ] OpenAI API 키를 발급받았고 크레딧 충전과 조직 인증을 마쳤다
- [ ] ZIP 압축을 풀었고, 일반 윈도우(x64) 노트북이다 (ARM 윈도우 미지원)
- [ ] Claude 앱을 트레이 아이콘까지 완전히 종료했다
- [ ] `install.bat`을 파일 탐색기에서 더블클릭한다 (Claude에게 실행을 맡기지 않는다)

Claude Code에서 OpenAI GPT Image로 이미지를 만들 수 있게 연결합니다.
Claude 앱과 Claude Code는 이미 쓰고 있다고 가정합니다.

## 순서

1. **OpenAI 가입**: https://platform.openai.com (ChatGPT 구독과 별개)
2. **결제 등록**: Billing에서 카드 등록 후 크레딧 충전
3. **조직 인증**: Settings → Organization → General → Verify Organization (신분증 인증, 반영에 시간이 걸릴 수 있음)
4. **API 키 발급**: API keys → Create new secret key → 권한 All → `sk-`로 시작하는 키를 메모장에 복사
5. **압축 풀기**: ZIP을 받았다면 반드시 압축을 푼 뒤 진행
6. **Claude 앱 완전 종료**: 창을 닫고, 트레이 아이콘(작업 표시줄 오른쪽 아래)에서도 종료
7. **`install.bat` 더블클릭**: 차단 창이 뜨면 아래 "실행이 막힐 때" 참고
8. **키 붙여넣기 후 엔터**: 별표로 보이거나 아무것도 안 보여도 정상
9. **질문 2개에 엔터**: 권한 허용, 시험 이미지 생성 (시험 이미지는 크레딧이 소량 차감)
10. **`시험 이미지 생성 성공`과 `설치 완료` 확인** 후 아무 키나 눌러 창 닫기
11. **Claude 앱 실행 → Code 탭**: 이제 이미지 생성 요청을 하면 됩니다

만든 이미지는 **실제 다운로드 폴더 안의 `openai-images`** 폴더에 저장됩니다. 다운로드 폴더를 OneDrive나 다른 드라이브로 옮겼다면 옮긴 곳에 저장되고, 정확한 위치는 설치 창 마지막 줄에 나옵니다.

## 사용 모델

기본 모델은 **gpt-image-2**입니다. 패키지 원래 기본값인 `gpt-image-1`은 OpenAI 공지상 2026년 10월 23일 종료 대상이어서, 설치할 때 설치 폴더의 사본만 기본값을 바꿉니다. `gpt-image-1`이나 `gpt-image-1.5`(공지상 2026년 12월 1일 종료 예정)를 직접 지정하면 실패할 수 있습니다.

## Node.js

- 없으면 `install.bat`이 winget으로 자동 설치를 시도합니다. 관리자 권한이 없거나 winget이 없으면 실패하며, 이때는 https://nodejs.org/dist/latest-v24.x/ 에서 x64 msi를 직접 설치하세요.
- **Node.js 22, 24, 26만 지원합니다.** 다른 버전이면 이유를 알려주고 중단합니다. 실제로 설치와 실행을 확인한 버전들입니다.
- 나중에 Node.js 버전을 바꾸면 이미지 도구가 안 켜질 수 있습니다. 이때는 `install.bat`을 다시 실행하세요.

**API 키를 바꾸려면** `install.bat`을 다시 실행하고 새 키를 붙여넣으면 됩니다. 이미 설치된 부분은 건너뛰고 키만 바뀝니다.

`install.bat`은 여러 번 실행해도 안전합니다. 이미 같은 버전이 정상으로 켜지면 설치를 건너뛰고 설정만 다시 등록하며, 켜지지 않으면 다시 설치합니다.

## 실행이 막힐 때

- **파일 속성 → 차단 해제**: 받은 ZIP 파일을 오른쪽 클릭 → 속성 → 아래쪽 "차단 해제" 체크 → 확인. 그다음 압축을 풉니다.
- **SmartScreen ("Windows의 PC 보호" 파란 창)**: 추가 정보 → 실행
- **스마트 앱 컨트롤**: 켜져 있으면 인터넷에서 받은 스크립트가 막힐 수 있습니다. 이 기능을 끄면 다시 켜기 어려울 수 있으니, 끄기 전에 본인 노트북인지 확인하세요. 설정 → 개인 정보 및 보안 → Windows 보안 → 앱 및 브라우저 컨트롤에서 확인합니다.
- **백신**: bat, ps1, node 실행을 막으면 백신에서 이 폴더를 허용합니다.
- **회사 정책**: 회사 노트북에서 스크립트 실행 자체가 금지되어 있으면 사용자가 풀 수 없습니다. IT 담당자에게 문의하세요.

## 제한 사항

- **프록시 환경은 지원이 확인되지 않았습니다.** 접속 확인은 프록시 없이 직접 접속으로 합니다. 프록시를 거쳐야만 인터넷이 되는 회사망에서는 접속 불가로 중단될 수 있습니다.
- ARM 윈도우는 지원하지 않습니다.

## 설치 후 Claude에서 이미지 도구가 안 보이면

- 일반 채팅이 아니라 **Code 탭**에서 쓰고 있는지 확인
- Claude 앱을 트레이까지 완전히 종료한 뒤 다시 실행
- Node.js를 방금 설치했다면 컴퓨터 재시작
- 그래도 안 되면 `install.bat` 다시 실행

## 제거

`uninstall.bat`을 더블클릭합니다. Claude 설정의 항목과 권한, 설치 폴더(`%LOCALAPPDATA%\openai-gpt-image-mcp`)와 이미지 생성 기록(`%LOCALAPPDATA%\openai-gpt-image-mcp-data`)을 지우고, 키가 든 백업을 지울지 물어봅니다. Node.js와 만든 이미지는 지우지 않습니다.

## 주의

- API 키는 다음 파일들에 암호화 없이 저장됩니다. 이 파일들을 남에게 보내지 마세요.
  - `%USERPROFILE%\.claude.json`
  - 같은 위치의 `.claude.json.backup-날짜` (이 설치가 만든 백업, 최근 3개만 보관)
  - `%USERPROFILE%\.claude\backups` 폴더 (Claude가 자동으로 만드는 백업)
- 이 설치 폴더에는 키가 들어 있지 않으므로 다른 사람에게 줘도 됩니다.
- 이미지 생성은 장당 과금됩니다.
- 이미지는 위 저장 폴더 안에만 저장됩니다. 다른 폴더가 필요하면 Claude에게 저장 후 옮겨 달라고 요청하세요.
