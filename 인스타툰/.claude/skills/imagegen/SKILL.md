# imagegen — 인스타툰 이미지 생성

## 1. 그리기 전에 반드시 할 일
- 프로젝트 루트의 `CLAUDE.md` 2장(주인공 설정)과 7장(이미지 규칙)을 읽는다.
- **`references/style_prompt.md`를 읽는다.** 캐릭터·표정·그림체·말풍선 자리·금지 문구는 이 파일의 문구를 그대로 쓴다.
- `references` 폴더의 기준 이미지를 확인한다(`charsheet_hangyeol.png`, `charsheet_bookmark.png`).

## 2. 사용 도구
- 그림은 `openai-gpt-image` MCP 도구로 만든다.
  - 기준 이미지가 **없으면**: `generate_image`
  - 기준 이미지가 **있으면**: `edit_image`를 쓰고 `reference_image_path`에 기준 이미지를 넣는다. 캐릭터 유지를 위해 `input_fidelity: high`로 둔다.
- 모델: `gpt-image-2` 기본

## 2-1. 크기와 비율
- **기본(인스타 피드용)**: `1024x1536`으로 생성한 뒤 **4:5로 잘라 `1080x1350`으로 저장**한다.
- 사용자가 **다른 비율**을 요청하면 그 비율로 만든다(인스타툰 외 용도 포함). 생성 크기는 목표 비율에 가장 가까운 것을 고른다.

| 목표 비율 | 생성 크기 | 최종 크기(기본) |
|---|---|---|
| 4:5 (기본) | `1024x1536` | `1080x1350` |
| 세로형(9:16, 2:3 등) | `1024x1536` | 가로 1080 기준 |
| 1:1 | `1024x1024` | `1080x1080` |
| 가로형(16:9, 3:2 등) | `1536x1024` | 가로 1080 기준, 또는 요청한 크기 |

- 자르기·크기 조정은 아래 스크립트로 한다. 그림을 새로 그리지 않는다.
  ```bash
  python .claude/skills/imagegen/scripts/fit_ratio.py <생성 원본> <최종 경로>
  python .claude/skills/imagegen/scripts/fit_ratio.py <생성 원본> <최종 경로> --ratio 16:9 --size 1920x1080
  ```
  - 기본은 가운데 기준으로 자른다. 인물이 위나 아래로 치우쳐 잘리면 `--anchor top` 또는 `--anchor bottom`을 쓴다.

## 3. 프롬프트 규칙
- 프롬프트는 **영어**로 쓰고, `references/style_prompt.md`의 **조합 순서**를 따른다(기준 이미지 설명 → 장면 → 인물·표정 → 그림체 → 구도·말풍선 자리 → 금지).
- **그림 안에 글자를 넣지 않는다.** 한글이 깨지기 때문이다. style_prompt.md의 금지 문구를 항상 넣는다.
- **잘려도 인물이 안 잘리게** "중요한 내용은 가운데, 위아래 여백 확보"를 넣는다(style_prompt.md 5장 구도 문구).
  - 가로로 자르는 비율(1:1 등)이면 "좌우 여백 확보"로 바꿔 쓴다.
- **말풍선 자리를 비워 둔다.** 어디를 얼마나 비울지는 콘티의 말풍선 자리(위·아래 20~30%)를 따른다. 4:5로 자르면 위아래 약 8%가 잘리므로, style_prompt.md 5장 표대로 그만큼 더해서 프롬프트에 쓴다.

## 4. 품질
- 테스트·시안: `quality: low`
- 인스타툰 컷 최종본: `quality: medium`
- 캐릭터 시트 등 기준 이미지: `quality: high`
- 사용자나 다른 스킬(instatoon)이 따로 지정하면 그 값을 따른다.

## 5. 저장
- 이 MCP는 `C:\Users\김우진\Downloads\openai-images` 안에만 저장할 수 있다. 먼저 그곳에 생성한 뒤, `fit_ratio.py`로 자르고 크기를 맞춰 프로젝트의 `output` 폴더에 저장한다. 생성 원본은 Downloads 쪽에 그대로 둔다.
- 같은 이름이 있으면 MCP가 `_1` 등을 붙이므로, 도구 결과에 나온 실제 파일명을 확인해 그 파일을 입력으로 쓴다.
- 캐릭터 시트처럼 자르면 안 되는 기준 이미지는 자르지 않고 생성 크기 그대로 복사한다.
- 기준 이미지 경로가 거부되면, 기준 이미지를 위 폴더에 먼저 복사해 그 경로를 넣는다.
- 파일명은 알아보기 쉽게 짓는다.
  - 컷 이미지: `날짜_형식_컷번호.png` (예: `20261102_C_01.png`)
  - 캐릭터 시트: `charsheet_캐릭터명.png` (예: `charsheet_hangyeol.png`)
  - 테스트: `test_내용.png` (예: `test_hangyeol_sofa.png`)
  - 사용자가 이름을 지정하면 그 이름을 쓴다.

## 6. 생성 후 확인
- 저장한(잘라낸) 이미지를 직접 열어 확인한다.
- 다음 중 하나라도 해당하면 사용자에게 알리고 다시 생성할지 묻는다. (instatoon으로 진행 중이면 묻지 않고 instatoon의 재시도 한도 안에서 다시 만든다.)
  - 비워 둬야 할 말풍선 자리에 인물이나 중요한 물건이 있음
  - 자르면서 인물의 얼굴이나 머리가 잘림 (먼저 `--anchor`를 바꿔 다시 잘라 본다)
  - 그림 안에 글자가 들어감
  - 외형이 CLAUDE.md 설정과 다름 (머리, 안경, 옷 색, 토트백, 고양이 무늬)
- 보고할 때는 저장 경로, 품질, 확인 결과를 함께 알린다.
