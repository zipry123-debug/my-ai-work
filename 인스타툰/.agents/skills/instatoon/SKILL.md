# instatoon — 인스타툰 한 편 제작 총괄

## 입력
- **주제**(책 또는 독서 정보 주제)만 있으면 된다.
- 컷 수: 지정이 없으면 **8컷**(AGENTS.md 3장 "8컷 템플릿"). 지정하면 최대 10컷.
- 형식(B 테마 리스트형 / C 독서 정보 공유형)은 주제에 맞게 AGENTS.md 3장에서 고른다. 책 한 권 소개는 C형으로 본다.

## 진행 원칙
- 1~6단계는 **사용자에게 묻지 않고 끝까지 진행한다.** imagegen 스킬의 "다시 생성할지 사용자에게 묻는다" 규칙은 이 스킬에서는 적용하지 않고, 아래 재시도 한도 안에서 스스로 다시 만든다.
- **7단계에서 반드시 멈추고 승인을 기다린다.** 승인 없이 업로드하거나 외부에 게시하지 않는다.
- 작업 전에 `AGENTS.md`와 `references/style_prompt.md`를 읽는다.
- **모든 최종 결과물은 인스타 피드 4:5, 1080x1350**이다.
- **번역서·원서 문장은 인용하지 않는다**(그림, 말풍선, 캡션 모두). 내용은 직접 요약한다.
- 결과물에 '정훈'이라는 이름은 쓰지 않는다.

## 재시도와 예산 한도
| 항목 | 한도 |
|---|---|
| 그림 재생성 | 컷당 2번, 한 편 전체 4번 |
| 말풍선 위치 수정 | 컷당 3번 |
| **한 편 예산** | **$2.00** (이미지 도구가 표시한 예상 비용 합계 기준) |

- 다음 생성으로 예산을 넘을 것 같으면 **생성하지 않고** 그 자리에서 7단계 보고로 넘어간다. 못 만든 컷과 남은 예산을 적는다.
- 참고: medium 품질 `edit_image` 1장은 지금까지 약 $0.14였다(도구 추정치). 8컷이면 약 $1.1, 재생성 4번을 더하면 약 $1.7.
- 한도에 걸려 해결하지 못한 문제는 7단계 "남은 문제"에 적는다.

## 작업 폴더
`날짜`는 오늘 날짜 `YYYYMMDD`, `주제`는 짧은 한글 이름(예: `20261102_소송`).

```
output/날짜_주제/
├── conti.json      # 콘티 원본 (장면·표정·대사·말풍선 위치·출처). 대사는 여기서만 고친다
├── conti.md        # conti.json에서 자동 생성되는 읽기용 콘티
├── cuts/           # 3단계: 말풍선 없는 그림 (1080x1350)
├── final/          # 4단계: 말풍선을 넣은 완성 컷 (1080x1350)
├── caption.txt     # 5단계: 캡션과 해시태그
└── preview.png     # 6단계: 전체 컷 미리보기 한 장
```

## 1. 조사
- AGENTS.md 4장 **정보 정확성 규칙**을 따른다.
  - 책 제목, 저자, 번역자, 출판사, 출간 연도 등 사실 하나하나를 **서로 다른 출처 2개 이상**으로 확인한다(출판사 공식 페이지, 온라인 서점, 백과사전 등).
  - 고전은 번역자와 출판사를 반드시 확인한다.
  - 확인하지 못한 정보는 쓰지 않거나 `unconfirmed`에 넣는다.
- 결말·반전은 스포일러하지 않는다.
- 확인한 사실과 출처 URL은 `conti.json`의 `facts`에 기록한다.

## 2. 콘티 → `conti.json` → `conti.md`
- 컷 구성은 AGENTS.md 3장의 8컷 템플릿과 **표지·마지막 장 규칙**을 따른다.
- `conti.json` 형식 (bubble-adder가 그대로 읽는다):
  ```json
  {
    "title": "카프카 『소송』", "format": "C", "date": "20261102",
    "source_dir": "output/20261102_소송/cuts",
    "final_dir": "output/20261102_소송/final",
    "facts": [{"fact": "1925년 출간", "sources": ["URL1", "URL2"]}],
    "unconfirmed": [],
    "cuts": [
      {
        "image": "20261102_C_01.png", "role": "표지",
        "scene": "한결이 책을 들고 정면, 책갈피는 책 더미 위",
        "expression": {"한결": "미소", "책갈피": "뚱함"},
        "bubble_area": "아래 30%",
        "bubbles": [{"type": "title", "text": "첫 줄\n둘째 줄"}]
      }
    ]
  }
  ```
- **표정**은 `references/style_prompt.md`의 표정 표에 있는 것만 쓴다.
- **`bubble_area`**: 컷마다 말풍선을 둘 자리를 정한다. 위 또는 아래 20~30%, 필요하면 위와 아래 모두.
- **종류 구분**: bubble-adder의 "종류 구분" 표를 따른다.
  - 말 = `speech`, 속마음 = `thought`, 상황 설명·질문 = `narration`, 사실 정보 = `info`, 표지 제목 = `title`
- 컷당 말풍선·박스는 **3개 이하**(표지 제목 제외), 각각 **두 줄 이하**로 쓴다.
- 사실과 한결의 개인 판단(난이도, 추천 대상)을 구분해 쓴다.
- 작성 후 실행한다. 경고가 있으면 고친다.
  ```bash
  python .Codex/skills/instatoon/scripts/render_conti.py output/날짜_주제/conti.json
  ```

## 3. 그림 → `cuts/`
- **imagegen 스킬**을 따르되, 품질은 **medium**으로 한다.
- 기준 이미지: 두 캐릭터 시트를 합친 이미지를 MCP 허용 폴더에 만든다(처음 한 번).
  ```bash
  python .Codex/skills/instatoon/scripts/make_ref.py "C:\Users\김우진\Downloads\openai-images\ref_combined.png"
  ```
- 프롬프트는 `references/style_prompt.md`의 조합 순서대로 만든다.
  - 기준 이미지 설명 → 장면 → 인물·표정 → 그림체 → 구도·말풍선 자리(`bubble_area`를 생성 기준 값으로 바꿔서) → 금지 문구
- `edit_image`(1024x1536, medium, `input_fidelity: high`)로 생성한다. 그다음 `fit_ratio.py`로 4:5, 1080x1350으로 잘라 `cuts/`에 저장한다.
  ```bash
  python .Codex/skills/imagegen/scripts/fit_ratio.py "C:\Users\김우진\Downloads\openai-images\<생성 파일>.png" output/날짜_주제/cuts/날짜_형식_01.png
  ```
- 모든 컷을 직접 열어 확인한다. 아래 문제가 있으면 재시도 한도 안에서 그 컷만 다시 만든다.
  - 글자·기호가 들어감
  - 외형이 설정과 다름
  - 얼굴이 잘림 (먼저 `--anchor`로 다시 잘라 본다)
  - `bubble_area`가 비어 있지 않음
- 컷마다 도구가 표시한 **예상 비용**을 기록하고, 합계를 예산과 비교한다.

## 4. 말풍선 → `final/`
- **bubble-adder 스킬**을 따른다. 입력은 `conti.json` 그대로다.
- 각 컷 그림(`cuts/`)을 직접 열어 얼굴 위치를 `avoid`에, 말풍선 위치를 `pos`와 `tail`에 `conti.json`으로 적는다.
  ```bash
  python .Codex/skills/bubble-adder/scripts/add_bubbles.py output/날짜_주제/conti.json
  ```
- 결과를 모두 직접 열어 확인한다. 아래 문제가 있으면 `conti.json`을 고쳐 해당 컷만 다시 실행한다(`--only 03`, 컷당 3번까지).
  - 얼굴을 가림
  - 꼬리가 글자를 가로지름
  - 말풍선끼리 겹침
  - 경고가 남음
- 대사를 고치면 `render_conti.py`를 다시 실행해 `conti.md`를 맞춘다.

## 5. 캡션 → `caption.txt`
- AGENTS.md 8장 규칙을 따른다.
  - **캡션**: 3~5줄. 핵심 정보 요약 + 마지막 줄에 댓글 유도 질문.
  - **해시태그**: 10개 안팎. 큰 태그(`#책추천 #독서 #인스타툰 #북스타그램`)와 분야·작품 태그를 섞는다.
  - 계정 고유 태그는 계정명이 정해진 경우에만 넣는다.
- 캡션 안의 책 정보도 `facts`에 있는 것만 쓴다. 번역서 문장은 인용하지 않는다.

## 6. 최종 검수
아래를 모두 확인하고, 결과를 7단계 보고에 표로 넣는다.

| 항목 | 방법 |
|---|---|
| 맞춤법·띄어쓰기 | `conti.md`의 모든 대사와 `caption.txt`를 처음부터 다시 읽고 고친다. 고쳤으면 4단계를 해당 컷만 다시 실행한다 |
| 글자 잘림·깨짐 | `final/` 전 컷을 직접 열어 확인한다. add_bubbles 경고 0개 |
| 크기 통일 | 아래 명령이 `OK`여야 한다 |
| 출처 2개 | `render_conti.py` 결과에 "출처 2개 미만" 경고가 없어야 한다. 대사·캡션의 사실이 모두 `facts`에 있는지 대조한다 |
| 인용 | 번역서 문장 인용이 없는지 확인한다 |
| 표지·마지막 장 | AGENTS.md 3장 규칙에 맞는지 확인한다 |

```bash
python -c "import sys,glob; from PIL import Image; fs=sorted(glob.glob(sys.argv[1]+'/*.png')); s={f:Image.open(f).size for f in fs}; [print(f, *v) for f,v in s.items()]; print('OK' if fs and set(s.values())=={(1080,1350)} else 'MISMATCH')" output/날짜_주제/final
```

미리보기 한 장을 만들고 직접 열어 전체 흐름을 확인한다.
```bash
python .Codex/skills/instatoon/scripts/make_preview.py output/날짜_주제/final output/날짜_주제/preview.png
```

## 7. 보고 후 멈춤
아래 내용을 정리해 보여주고 **멈춘다.** 업로드 등 다음 단계는 진행하지 않는다.

1. **미리보기**: `preview.png` 경로
2. **완성된 컷 목록**: `final/` 파일 경로를 컷 번호 순서로. 컷마다 장면 한 줄 요약.
3. **캡션 전문**: `caption.txt` 내용 그대로
4. **사용한 출처**: 사실별 URL. `unconfirmed` 항목은 따로 표시
5. **최종 검수 결과**: 6단계 표
6. **비용**: 생성·재생성한 이미지별 예상 비용과 합계, 재생성 횟수, 예산 대비. 도구의 추정치이며 실제 청구액과 다를 수 있다고 밝힌다.
7. **남은 문제**: 한도 때문에 해결하지 못한 문제, 자르면서 잘린 부분 등

그다음 승인 또는 수정 요청을 기다린다.

## 수정 요청을 받았을 때
- **요청한 컷만** 다시 만든다. 다른 컷의 그림과 말풍선은 건드리지 않는다.
  - 그림 수정: 해당 컷만 3단계 → 4단계(`--only 컷번호`)
  - 대사·말풍선 수정: `conti.json`의 해당 컷만 고치고 `render_conti.py` → 4단계(`--only 컷번호`)
  - 캡션 수정: `caption.txt`만 고친다.
- 수정에도 같은 예산 한도를 적용한다. 추가 비용을 합계에 더한다.
- 다시 만든 뒤에는 6단계 검수(바뀐 컷)와 미리보기를 다시 하고, 7단계 형식으로 보고한 뒤 다시 멈춘다.
