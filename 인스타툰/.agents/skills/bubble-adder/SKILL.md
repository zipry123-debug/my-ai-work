# bubble-adder — 말풍선·대사 넣기

## 1. 준비 (처음 한 번)
- 파이썬과 Pillow가 필요하다. 없으면 설치한다.
  - 확인: `python -c "import PIL; print(PIL.__version__)"`
  - 설치: `python -m pip install --user pillow`
- 글꼴은 프로젝트의 `fonts` 폴더에 있는 **프리텐다드(Pretendard)** 를 쓴다. SIL Open Font License 1.1이라 상업적으로 무료로 쓸 수 있다(`fonts/Pretendard-LICENSE.txt`).
  - 없으면 아래 주소에서 `Pretendard-Bold.otf`, `Pretendard-ExtraBold.otf`를 받아 `fonts`에 넣는다.
  - `https://raw.githubusercontent.com/orioncactus/pretendard/v1.3.9/packages/pretendard/dist/public/static/Pretendard-Bold.otf`
  - `https://raw.githubusercontent.com/orioncactus/pretendard/v1.3.9/packages/pretendard/dist/public/static/Pretendard-ExtraBold.otf`

## 2. 콘티 파일
- 위치: instatoon으로 만들 때는 `output/날짜_주제/conti.json`(대사의 단일 원본). 따로 쓸 때는 `conti/날짜_형식_책제목.json` (예: `conti/20261030_C_소송.json`)
- 아래 항목 외의 키(장면, 표정 등)가 있어도 무시하고 읽는다.
- 좌표는 모두 **이미지 크기에 대한 퍼센트(0~100)** 다.

```json
{
  "source_dir": "output",
  "final_dir": "output/final",
  "cuts": [
    {
      "image": "20261030_C_01.png",
      "avoid": [[22, 19, 46, 42]],
      "bubbles": [
        {"type": "title", "text": "첫 줄\n둘째 줄", "pos": [50, 9]},
        {"type": "speech", "speaker": "한결", "text": "대사", "pos": [72, 26], "tail": [44, 30]}
      ]
    }
  ]
}
```

| 항목 | 뜻 |
|---|---|
| `avoid` | 가리면 안 되는 영역(인물 얼굴 등). `[x1, y1, x2, y2]` |
| `type` | 아래 "종류 구분" 표에서 고른다 |
| `pos` | 말풍선 중심 위치 `[x, y]`. 없으면 얼굴·다른 말풍선을 피해 그림이 단순한 곳에 자동 배치 |
| `tail` | 말풍선 꼬리가 향할 곳(말하는 인물의 입 근처). 얼굴을 가로지르지 않게 머리 옆이나 턱 아래를 가리킨다 |
| `\n` | 직접 줄을 바꿀 위치 |
| `size`, `max_width` | 필요할 때만 글자 크기(px, 가로 1080 기준)와 최대 폭(%)을 지정 |

### 종류 구분
| 내용 | `type` | 모양 | `tail` |
|---|---|---|---|
| 소리 내어 하는 말 | `speech` | 흰 바탕, 검은 테두리, 둥근 말풍선 + 뾰족한 꼬리 | 말하는 인물의 입 근처. 같은 인물이 이어 말하면 두 번째부터 생략 |
| 속마음·혼잣생각 | `thought` | 흰 바탕 구름 모양 + 작은 동그라미 꼬리 | 생각하는 인물의 머리 근처 |
| 상황 설명·내레이션·질문 | `narration` | 연한 노란 바탕 사각 박스 | 없음 |
| 사실 정보(책 정보, 번역본, 난이도, 요약) | `info` | 연한 하늘색 바탕 둥근 사각 박스 | 없음 |
| 표지 제목 | `title` | 흰 바탕 큰 박스, 굵은 글꼴 | 없음 |

- 사실 정보는 말풍선(`speech`)보다 `info` 박스에 넣는다. 인물의 개인 판단(예: "한결 기준 난이도")도 `info`에 넣되 판단임을 글로 밝힌다.

## 3. 말풍선 규칙
- 말풍선(`speech`)은 흰 바탕, 검은 테두리, 둥근 모양.
- **한 말풍선에 두 줄 이내.** 넘으면 글자를 최소 크기까지 줄이고, 그래도 넘으면 경고가 뜬다. 이때는 대사를 말풍선 두 개로 나눈다(내용은 바꾸지 않고 끊는 위치만 바꾼다).
- **기준 규격은 인스타 피드 4:5, `1080x1350`이다.** 입력 그림은 이 크기로 맞춰진 것을 쓴다(imagegen의 `fit_ratio.py`). 다른 크기면 실행 결과에 경고가 뜨고, 글자 크기와 여백은 가로 폭에 비례해 조정된다.
- 글자 크기는 1080x1350 기준 휴대폰에서 읽기 쉽게 정했다. 대사 48px(휴대폰에서 약 17pt), 최소 40px. 내레이션·정보 42px, 제목 68px.
- **화면 가장자리 60px 안쪽에만 글자를 넣는다.** 말풍선 전체를 가장자리에서 60px 안쪽에 둔다(`pos`를 가장자리에 가깝게 줘도 자동으로 안쪽으로 밀린다). 말풍선 꼬리는 글자가 아니므로 이 범위를 넘을 수 있다.
- **인물 얼굴을 가리지 않는다.** 콘티를 쓰기 전에 각 컷 이미지를 직접 열어 얼굴 위치를 `avoid`에 넣고, 말풍선 위치를 정한다.
- 읽는 순서대로 위→아래, 왼쪽→오른쪽에 둔다.

## 4. 실행
```bash
python .Codex/skills/bubble-adder/scripts/add_bubbles.py conti/20261030_C_소송.json
```
- 일부 컷만 다시 할 때: `--only 01,04`
- 원본 그림(`output`)은 건드리지 않는다. 결과는 `output/final`에 같은 파일명으로 저장된다.
- 실행 결과에 말풍선마다 줄 수, 글자 크기, 위치, 경고가 나온다.
  - `얼굴(avoid) 영역과 겹침`: 위치를 옮긴다.
  - `다른 말풍선과 겹침`: 위치를 옮기거나, 그 컷만 `size`를 줄인다.
  - `가장자리 60px 안쪽을 벗어남`: 말풍선이 너무 크다. 대사를 나누거나 `max_width`를 조정한다.
  - `이미지 크기 … (인스타 규격 1080x1350 아님)`: 입력 그림을 먼저 4:5, 1080x1350으로 맞춘다.

## 5. 확인
- 결과 이미지를 **모두 직접 열어** 확인한다.
  - 얼굴을 가리지 않는지
  - 글자가 잘리거나 깨지지 않았는지
  - 꼬리가 말하는 인물을 가리키는지
  - 휴대폰 크기에서 읽을 만한지
- 문제가 있으면 콘티의 `pos`, `tail`, `avoid`를 고쳐 해당 컷만 다시 실행한다. **한 컷당 최대 3번**까지 고치고, 그래도 남는 문제는 보고에 적는다.
- 보고할 때는 저장 경로, 확인 결과, 남은 경고를 함께 알린다.
