## 직접 추정한 값

- **아파트·공공기관 위치:** 버스 정류장 이름(예: "OO아파트", "OO행정복지센터")으로 추정했습니다. 실제와 다른 곳이 섞일 수 있습니다.
- **서해선 역 6곳:** 표준데이터에 없어서, 역 이름이 들어간 버스 정류장 좌표의 평균으로 위치를 추정했습니다.
- **케이크 판매 여부:** 상호·업종·가맹 브랜드 주요상품으로 자동 추정했습니다. 판매 여부를 알 수 없는 동네 빵집은 "미확인"으로 두었습니다.

## 쓰지 않은 자료

| 자료 | 이유 |
|---|---|
| 구글 지도 장소 정보 | 약관상 구글 지도가 아닌 지도에 표시 금지, 상호 저장 금지 |
| 카카오맵 분류 | 운영정책상 사용 제한 |
| 네이버 검색·블로그 | API 이용약관상 사용 제한 |
| 민영 주차장, 오픈스트리트맵 상세 정보 | 사용하지 않기로 결정 (오픈스트리트맵은 같은 조건 공개 의무) |

## 저장소에 넣지 않은 것

- 원자료 파일(용도지역 원본 약 2.9GB, SGIS 원자료, API로 받은 원자료 약 400MB)은 용량과 재배포 조건 때문에 넣지 않았습니다. `자료생성/` 코드는 이 원자료가 `자료생성/데이터/` 아래에 있다고 가정합니다.
- API 키 파일(`설정.env`)은 넣지 않았습니다.
