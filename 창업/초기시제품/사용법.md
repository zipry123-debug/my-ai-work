# 레터링 케이크 입지 조사 프로그램 사용법

## 실행

`실행.bat`을 더블클릭하면 브라우저가 열립니다. 끄려면 검은 창을 닫으세요.

화면만 먼저 보려면 이 폴더에서 아래 명령을 실행하세요. 숫자는 모두 가짜입니다.

```bash
python server.py --demo
```

## API 키 발급 (둘 다 무료, 최초 1회)

키는 화면 오른쪽 위 **API 키 설정**에 넣습니다. 이 컴퓨터의 `설정.env`에만 저장되니 다른 사람에게 보내지 마세요.

### 1. 카카오 REST API 키 (필수: 위치 찾기, 경쟁점 검색)

1. [카카오 개발자 사이트](https://developers.kakao.com/)에서 로그인하고 앱을 만듭니다.
2. 앱 설정의 앱 키에서 **REST API 키**를 복사합니다.
3. 앱 설정에 카카오맵 사용 설정이 있으면 켭니다. 꺼져 있으면 오류가 날 수 있습니다.

### 2. 공공데이터포털 인증키 (상가 현황, 개·폐업 이력)

[공공데이터포털](https://www.data.go.kr/)에 가입하고, 아래 API를 각각 **활용신청**합니다. 키는 하나지만 신청은 API마다 따로 합니다.

- [소상공인시장진흥공단_상가(상권)정보](https://www.data.go.kr/data/15012005/openapi.do)
- 행정안전부_식품_제과점영업 조회서비스 (포털에서 이름으로 검색)
- [행정안전부_식품_휴게음식점 조회서비스](https://www.data.go.kr/data/15154921/openapi.do)
- 행정안전부_식품_즉석판매제조가공업 조회서비스 (포털에서 이름으로 검색)

신청 후 마이페이지의 **일반 인증키**를 복사합니다. 인코딩·디코딩 키 모두 입력할 수 있습니다. 승인 직후에는 키가 바로 동작하지 않을 수 있습니다.

## 화면 읽는 법

| 항목 | 뜻 | 주의 |
|---|---|---|
| 레터링 경쟁점 | 카카오에서 "레터링케이크", "주문제작케이크"로 찾은 곳 | 인스타그램으로만 영업하는 공방은 빠짐 |
| 빵·제과 업소 | 상가정보에서 빵·제과 분류나 관련 상호로 추린 업소 | 일반 빵집 포함 |
| 제과점 개·폐업 | 인허가 자료의 제과점영업 건수 | 다른 업종으로 신고한 곳은 빠짐 |
| '케이크' 상호 | 제과점·휴게음식점·즉석판매제조가공업 중 상호에 '케이크'가 있는 곳 | 상호에 단어가 없으면 빠짐 |
| 동별 현황 | 해당 시군구 전체를 동별로 묶은 표 | 새 후보 동을 찾는 데 사용 |

"확인 불가"는 0건이 아니라 **자료를 못 받았다**는 뜻입니다.

경고 기준(최근 3년 폐업 3건 이상, 폐업이 개업 이상)은 공식 통계가 아니라 이 프로그램이 정한 실무 기준입니다. `core.py`에서 바꿀 수 있습니다.

조회 결과는 `cache` 폴더에 7일간 저장됩니다. 최신 자료가 필요하면 이 폴더를 지우세요.
